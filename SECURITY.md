# Security Policy

## Reporting a Vulnerability

We take the security and integrity of the Nymrel open-source ecosystem seriously.

If you discover a security vulnerability in `@nymrel/portal` or any of the 10 Nymrel core repositories:

1. **Email us directly**: Send details to `contact@jalenbuilds.com`.
2. **Do not create a public issue**: Please allow up to 48 hours for our team to triage and acknowledge the report.
3. **Include reproducer**: Where applicable, provide a minimal test case, reproduction script, or payload demonstration.

## Scope

- Zero-dependency execution firewalls (`@nymrel/agent-surety`)
- Copy-on-Write sandbox boundaries (`@nymrel/agent-sandstorm`)
- Universal Commerce Protocol payment verification (`@nymrel/open-ucp`)
- Cryptographic proof generation and Merkle tree validation (`@nymrel/proof-ledger`)
- Ecosystem portal integrity and package distribution (`@nymrel/portal`)

## Operating Entity
Nymrel is an operating umbrella of **JalenBuilds LLC**.
All security patches are reviewed and signed by the engineering team.
